🏠 House Price Prediction System
A machine learning project that predicts house prices based on features like area, number of bedrooms, location etc.

🛠️ Tools & Libraries Used
Python
Pandas, NumPy
Scikit-learn
Matplotlib / Seaborn
📌 What it does
Loads and cleans the dataset
Explores data with visualizations
Trains a ML model to predict prices
Evaluates model accuracy
